# Visual assets for `v0.1.0-beta`

The three supplied desktop screenshots are included in `docs/assets/` and displayed near the top of the README. No GIF is planned.

| File | Real application view |
| --- | --- |
| `docs/assets/collapsed.png` | Collapsed widget with 5-hour and weekly quota, Needs action and Done counters. |
| `docs/assets/expanded.png` | Expanded widget with quota row and three visible task states. |
| `docs/assets/settings.png` | Settings with Appearance, Window, shortcut, Sounds, Data, and Support entry. |

The source JPEGs were converted to PNG without changing the visible content. This also leaves their source metadata out of the repository images.

Before any public upload, review the text visible in `expanded.png`, especially the task titles, and confirm it is suitable for public display. Also check each image for prompts, client or project names, email addresses, usernames, filesystem paths, notification content, API keys, tokens, machine identifiers, private browser tabs, and personal desktop files. The displayed quota values are from the supplied real captures and have not been replaced.
