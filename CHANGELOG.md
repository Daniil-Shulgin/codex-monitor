# Changelog

## v0.1.0-beta

- Windows widget for local Codex work in VS Code, with collapsed and expanded views.
- 5-hour and weekly quota indicators with reset countdowns.
- Running, Needs action, and Done task states, task names, and elapsed time in the expanded view.
- Optional always-on-top and click-through modes, configurable global shortcut, and system-tray controls.
- Sound alerts for Needs action and Done with volume and event controls.
- Fixed notification sounds ending early on some Windows audio devices.
- Dark, Light, and System themes, opacity setting, and optional Start with Windows.
- Optional Support dialog in Settings.
